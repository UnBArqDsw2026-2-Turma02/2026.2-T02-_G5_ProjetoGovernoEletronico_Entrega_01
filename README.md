# Projeto Governo Eletrônico

Repositório do Grupo 5 da disciplina **Arquitetura e Desenho de Software (FGA0208)**, turma 02, da Universidade de Brasília, referente ao semestre 2026.2 e à Entrega 01.

O projeto investiga uma solução de governo eletrônico voltada ao acesso à informação pública, com ênfase em **privacidade de dados**, **usabilidade** e **experiência do usuário**. O portal Informa.BR é utilizado somente como referência de domínio para compreender atores, fluxos e oportunidades de melhoria; a solução proposta pelo grupo mantém identidade própria.

## Documentação

A documentação publicada está disponível no [GitHub Pages](https://unbarqdsw2026-2-turma02.github.io/2026.2-T02-_G5_ProjetoGovernoEletronico_Entrega_01/).

Nesta entrega, o grupo desenvolve e registra:

- artefatos generalistas, como Mapa Mental e Rich Picture;
- Softgoal Interdependency Graphs (SIGs), conforme o NFR Framework;
- engenharia reversa de fluxos de acesso à informação;
- modelagens de processo em BPMN;
- análise crítica do emprego de IA generativa;
- atas, histórico de versões e evidências de participação;
- uma Design Sprint complementar para exploração do problema.

## Como contribuir

O workflow de GitHub Actions publica automaticamente o conteúdo de `docs/` no GitHub Pages após alterações na branch `main`. Ele também pode ser iniciado manualmente pela aba **Actions** do repositório.
