# 1.3. Iniciativas Extras

## Design Sprint

Como iniciativa complementar à entrega, o grupo realizou uma **Design Sprint** com o objetivo de auxiliar na escolha da aplicação governamental utilizada como inspiração para o projeto e facilitar a compreensão inicial do problema.

A atividade foi realizada seguindo uma adaptação do processo proposto por **Google Ventures (GV Sprint)**.

Durante a etapa inicial, foram avaliadas diferentes aplicações de Governo Eletrônico, considerando critérios como privacidade de dados, usabilidade e experiência do usuário. Após discussão entre os integrantes, o grupo selecionou o **Informa.BR**, sistema da Controladoria-Geral da União (CGU), como principal referência para análise.

A partir da escolha da aplicação, cada integrante desenvolveu uma Rich Picture representando sua visão sobre o fluxo do sistema, os atores envolvidos, os problemas identificados e possíveis oportunidades de melhoria. Posteriormente, foi escolhido o melhor artefato para representar o fluxo da solução.

Também foi desenvolvido um protótipo inicial de alta fidelidade visual simplificado, elaborado por Pedro Henrique Martins Silva, utilizando como base os elementos identificados durante a análise da aplicação e as discussões realizadas na Design Sprint.
